# Horcrux Environment

A Gymnasium environment for reinforcement learning with snake robots. Based on the MuJoCo physics simulator, this environment provides snake robot locomotion pattern generation and control capabilities.

## Installation

```bash
cd horcrux_env
pip install -e .
```

### Dependencies

- `gymnasium`: Standard interface for reinforcement learning environments
- `mujoco>=3.4.0`: Physics simulator
- `pygame>=2.1.3`: Rendering support
- `pre-commit`: Code quality management

## Environments

### PlaneJoyDirWorld (`horcrux_env/plane-v0`)

A MuJoCo-based snake robot environment that enables directional control through joystick input.

#### Features

- **Gait Pattern Generation**: Uses the `GaitV2` class to generate Serpenoid curve-based locomotion patterns
- **Directional Control**: Directional control through joystick input (X-axis velocity, Y-axis velocity, Yaw angular velocity)
- **Diverse Reward Functions**: Forward reward, rotation reward, efficiency reward, health reward, and more
- **Filtering Options**: Moving average filters can be applied to IMU data and velocity data

#### Observation Space

A continuous space of type `Box(low=-inf, high=inf, shape=(97,))` containing the following information:

- **Joint Information** (42 dimensions):
  - Joint positions (14 dimensions): `sensordata[0:14]`
  - Joint velocities (14 dimensions): `sensordata[14:28]`
  - Joint torques (14 dimensions): `sensordata[28:42]`
- **Contact Information** (28 dimensions):
  - Top link contacts (14 dimensions, binary): `sensordata[42:56]` (1 if value > 1, else 0)
  - Bottom link contacts (14 dimensions, binary): `sensordata[56:70]` (1 if value > 1, else 0)
- **Head IMU Information** (10 dimensions):
  - Head orientation (quaternion, 4 dimensions): `sensordata[70:74]`
  - Head angular velocity (3 dimensions): `sensordata[74:77]`
  - Head linear acceleration (3 dimensions): `sensordata[77:80]`
- **Motion Vector** (14 dimensions): Current locomotion pattern motion vector (generated by `GaitV2`)
- **Joystick Input** (3 dimensions): Target direction and angular velocity `[X velocity, Y velocity, Yaw angular velocity]`

Total observation space size: 80 (sensordata) + 14 (motion_vector) + 3 (joy_input) = 97 dimensions

#### Action Space

A continuous space of type `Box(low=0, high=2.7, shape=(14,))` representing control inputs for 14 joints. Actions are multiplied with the motion vector to generate actual joint torques.

#### Reward Function

The environment's reward is composed as follows:

**Reward Components:**
- `linear_movement_reward`: Reward for linear movement in the target direction
- `angular_movement_reward`: Reward for rotation at the target angular velocity
- `efficiency_reward`: Efficiency reward (more movement with less control effort)
- `healthy_reward`: Health state reward (roll angle within normal range)

**Cost Components:**
- `ctrl_cost`: Control input cost
- `unhealthy_cost`: Unhealthy state cost
- `orientation_cost`: Posture cost (roll angle)
- `yaw_vel_cost`: Unnecessary yaw angular velocity cost
- `proj_dist_cost`: Straightness cost

Final reward = Sum of reward components - Sum of cost components

#### Key Parameters

```python
env = gym.make(
    "horcrux_env/plane-v0",
    # Reward weights
    forward_reward_weight=60.0,      # Forward reward weight
    rotation_reward_weight=45.0,      # Rotation reward weight
    efficiency_reward_weight=3.0,     # Efficiency reward weight
    healthy_reward=2.0,               # Health reward
    ctrl_cost_weight=0.0,             # Control cost weight
    rotation_norm_cost_weight=0.5,     # Posture cost weight
    unhealthy_cost_weight=2.0,        # Unhealthy state cost weight
    
    # Gait pattern parameters (e_d1, e_l1, e_d2, e_l2, delta)
    gait_params=(30, 30, 40, 40, 23), # Gait pattern parameters
    
    # Joystick input
    joy_input=(1, 0, 0),              # (X velocity, Y velocity, Yaw angular velocity)
    joy_input_random=True,            # Use random joystick input
    
    # Health state settings
    healthy_roll_range=(-45, 45),     # Normal roll angle range (degrees)
    terminating_roll_range=(-120, 120), # Termination roll angle range (degrees)
    terminate_when_unhealthy=True,     # Terminate when unhealthy
    unhealthy_max_steps=30,            # Maximum consecutive unhealthy steps
    
    # Filtering options
    use_imu_window=False,             # Use moving average filter for IMU data
    use_vels_window=False,            # Use moving average filter for velocity data
    
    # Miscellaneous
    frame_skip=10,                    # Frame skip
    gait_sampling_interval=0.05,      # Gait pattern sampling interval
    use_friction_chg=False,           # Use friction coefficient changes
    render_camera_name="ceiling",     # Rendering camera name
)
```

#### Usage Examples

**Basic Usage:**

```python
import gymnasium as gym
import horcrux_env

# Create environment
env = gym.make("horcrux_env/plane-v0")

# Initialize environment
obs, info = env.reset()
print(f"Observation space shape: {env.observation_space.shape}")  # (97,)
print(f"Action space shape: {env.action_space.shape}")  # (14,)

# Run episode
for _ in range(1000):
    # Random action (in practice, use agent's policy)
    action = env.action_space.sample()
    
    # Execute step
    obs, reward, terminated, truncated, info = env.step(action)
    
    # Check termination conditions
    if terminated or truncated:
        obs, info = env.reset()

env.close()
```

**Creating Environment with Custom Parameters:**

```python
import gymnasium as gym
import horcrux_env

# Create environment with custom parameters
env = gym.make(
    "horcrux_env/plane-v0",
    forward_reward_weight=60.0,
    rotation_reward_weight=45.0,
    gait_params=(30, 30, 40, 40, 23),
    joy_input_random=True,
    use_imu_window=True,  # Enable IMU data filtering
    use_vels_window=True,  # Enable velocity data filtering
    render_mode="human"  # Enable rendering
)

obs, info = env.reset()

for step in range(100):
    action = env.action_space.sample()
    obs, reward, terminated, truncated, info = env.step(action)
    
    # Check reward information
    print(f"Step {step}: Reward = {reward:.3f}, "
          f"Linear Movement = {info['reward_linear_movement']:.3f}, "
          f"Angular Movement = {info['reward_angular_movement']:.3f}")
    
    if terminated or truncated:
        obs, info = env.reset()

env.close()
```

#### Info Dictionary

The `info` dictionary returned by the `step()` method contains the following information:

**State Information:**
- `step`: Current step number
- `x_velocity`, `y_velocity`, `yaw_velocity`: Current velocities (m/s, rad/s)
- `x_displacement`, `y_displacement`: Displacement from previous step
- `distance_from_origin`: Distance from origin
- `com_pos`: Center of mass position (3D)
- `com_ypr`: Center of mass Yaw-Pitch-Roll angles (degrees)
- `step_ypr`: Rotation change between steps (Yaw-Pitch-Roll, degrees)
- `init_rpy`, `init_com`, `init_head_rpy`: Initial state information

**Joint and Sensor Information:**
- `joint_pos`: Joint positions (14 dimensions)
- `joint_vel`: Joint velocities (14 dimensions)
- `head_quat`: Head orientation quaternion (4 dimensions)
- `head_ang_vel`: Head angular velocity (3 dimensions)
- `head_lin_acc`: Head linear acceleration (3 dimensions)

**Gait Pattern Information:**
- `motion_vector`: Current motion vector (14 dimensions)
- `motionMatrix`: Full motion matrix
- `gait_params`: Gait pattern parameter tuple
- `joy_input`: Joystick input (3 dimensions)

**Physics Information:**
- `friction_coeff`: Friction coefficients `[slide, torsion, roll]` (when friction changes are enabled)

**Reward and Cost Details:**
- `reward_linear_movement`: Linear movement reward
- `reward_angular_movement`: Angular movement reward
- `reward_efficiency`: Efficiency reward
- `reward_healthy`: Health reward
- `cost_ctrl`: Control cost
- `cost_unhealthy`: Unhealthy state cost
- `cost_orientation`: Posture cost
- `cost_yaw_vel`: Yaw velocity cost
- `cost_proj_dist`: Straightness cost
- `direction_similarity`: Direction similarity (-1 ~ 1)
- `rotation_alignment`: Rotation alignment (-1 or 1)
- `velocity_theta`: Velocity direction angle

## Wrappers

Several wrapper classes are provided to modify or extend the environment.

### ClipReward

A Reward Wrapper that clips rewards to a specified range.

```python
from horcrux_env.wrappers import ClipReward
import gymnasium as gym

env = gym.make("horcrux_env/plane-v0")
env = ClipReward(env, min_reward=-10.0, max_reward=10.0)
```

### DiscreteActions

An Action Wrapper that converts a continuous action space to a discrete action space.

```python
from horcrux_env.wrappers import DiscreteActions
import gymnasium as gym

env = gym.make("horcrux_env/plane-v0")
# Define discrete action list
disc_to_cont = [
    [0.0] * 14,
    [1.0] * 14,
    [2.0] * 14,
]
env = DiscreteActions(env, disc_to_cont)
```

### RelativePosition

An Observation Wrapper that converts the observation space to relative position.

```python
from horcrux_env.wrappers import RelativePosition
import gymnasium as gym

env = gym.make("horcrux_env/plane-v0")
env = RelativePosition(env)
```

### ReacherRewardWrapper

A wrapper that adjusts the weights of reward components.

```python
from horcrux_env.wrappers import ReacherRewardWrapper
import gymnasium as gym

env = gym.make("horcrux_env/plane-v0")
env = ReacherRewardWrapper(
    env,
    reward_dist_weight=1.0,
    reward_ctrl_weight=0.1
)
```

## Gait Pattern Generator (GaitV2)

The `GaitV2` class generates snake robot locomotion patterns based on Hirose's (1993) Serpenoid curve. This class generates periodic motion vectors for 14 joints to implement snake locomotion patterns.

### Parameters

- `e_d1` (float): Dorsal spatial parameter (degrees) - amplitude of dorsal curve
- `e_l1` (float): Lateral spatial parameter (degrees) - amplitude of lateral curve
- `e_d2` (int): Dorsal temporal parameter - frequency of dorsal curve
- `e_l2` (int): Lateral temporal parameter - frequency of lateral curve
- `delta` (float): Phase difference (degrees) - phase difference between dorsal and lateral curves
- `reverse` (int, optional): Reverse flag (>0: forward, <0: backward)

### Serpenoid Curve

Each joint angle is calculated using the following Serpenoid curve:

```
θ_i = sin(e_d1 * i + e_d2/10 * t) + sin(e_l1 * i * 2 + e_l2/10 * t + delta)
```

where `i` is the joint number (1-14) and `t` is time.

### Usage Example

```python
from horcrux_env.envs.gait_v2 import GaitV2
import numpy as np

# Initialize gait pattern generator
gait = GaitV2(
    params=(30, 30, 40, 40, 23),  # (e_d1, e_l1, e_d2, e_l2, delta)
    sampling_t=0.05,  # Sampling interval (seconds)
    frame_skip=10     # Frame skip
)

# Get motion vector at specific time step
motion_vector = gait.getMvec(k=100)  # k is the time step
print(f"Motion vector shape: {motion_vector.shape}")  # (14,)

# Get full motion matrix
motion_matrix = gait.getMotionMat()
print(f"Motion matrix shape: {motion_matrix.shape}")  # (14, M) - M is the period length
```

### Motion Vector

The motion vector is a sign vector representing the torque direction for each joint:
- `+1`: Positive torque direction
- `-1`: Negative torque direction

This vector is multiplied with the environment's action to generate actual control inputs.

## Rendering

The environment supports the following rendering modes:

- `human`: Real-time rendering on screen (default: `None`)
- `rgb_array`: Returns RGB image array (numpy array)
- `depth_array`: Returns depth image array (numpy array)

### Rendering Examples

```python
import gymnasium as gym
import horcrux_env
import numpy as np

# Screen rendering
env = gym.make("horcrux_env/plane-v0", render_mode="human")
obs, info = env.reset()

for _ in range(100):
    action = env.action_space.sample()
    obs, reward, terminated, truncated, info = env.step(action)
    if terminated or truncated:
        obs, info = env.reset()

env.close()

# RGB array rendering
env = gym.make("horcrux_env/plane-v0", render_mode="rgb_array")
obs, info = env.reset()
action = env.action_space.sample()
obs, reward, terminated, truncated, info = env.step(action)

# Get RGB image
rgb_image = env.render()
print(f"RGB image shape: {rgb_image.shape}")  # (height, width, 3)

env.close()
```

### Camera Settings

The default rendering camera is `"ceiling"`. To use a different camera, set the `render_camera_name` parameter.

## Additional Features

### Moving Average Filters

The environment provides moving average filters for IMU data and velocity data:

- **IMU Filtering** (`use_imu_window=True`): Applies moving average filter to head orientation, angular velocity, and linear acceleration
- **Velocity Filtering** (`use_vels_window=True`): Applies moving average filter to X/Y velocities and Yaw angular velocity

Using filters can reduce noise and improve learning stability.

### Friction Coefficient Changes

When `use_friction_chg=True` is set, random friction coefficients are applied each episode:

- Slide friction: 0.6 ~ 0.8
- Torsion friction: 0.013 ~ 0.017
- Roll friction: 0.0008 ~ 0.0012

This enables learning robustness across various ground conditions.

### Health State Management

The environment monitors the snake robot's posture to determine health state:

- **Normal Range** (`healthy_roll_range`): Roll angle within this range is considered healthy
- **Termination Range** (`terminating_roll_range`): Roll angle outside this range is considered unhealthy
- **Maximum Consecutive Steps** (`unhealthy_max_steps`): Episode terminates if unhealthy state persists for this many steps
