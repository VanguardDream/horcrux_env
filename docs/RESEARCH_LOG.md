# 연구 일지

실험 하나가 한 항목이다. 새 항목은 맨 위에 더한다. 숫자는 `results/` 아래 결과 JSON에서 온 것만 적고,
판정은 비판적 검토를 거친 문장만 적는다. 발표 덱(`docs/deck_src/build_deck_plain.py`)의 슬라이드와
일대일로 맞춘다. 이 파일을 쓰는 절차는 `/report` 커맨드(`.claude/commands/report.md`)에 있다.

항목 틀:

```
## YYYY-MM-DD — 실험 이름
- 질문: 무엇을 알고 싶었나
- 설정: 정책·환경·조건·표본 수
- 결과 파일: results/... (스크립트)
- 판정: 검토를 거친 문장
- 슬라이드: 덱 이름과 슬라이드 제목
- 다음 후보: 이 결과가 가리키는 다음 실험
- 검토에서 고친 점: 검토가 바꾼 해석
```
