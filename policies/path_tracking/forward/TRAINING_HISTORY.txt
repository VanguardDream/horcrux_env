Horcrux 뱀 로봇 경로 추종 정책 이력 - 전진 방향
==================================================

작성일: 2026-07-18
환경: horcrux_env/plane-v0
정책 프레임워크: Stable-Baselines3 PPO
목적: 뱀 로봇 경로 추종에서 로봇 기준 전진(+X) 명령을 수행하는 정책 보관
명령 벡터: joy_input = [1.0, 0.0, 0.0]

보관 방식:
  2026-07-18에 아래 5개의 원본 run 디렉터리를 runs/에서 이 폴더로 이동했다.
  각 단계는 정책만 추출한 복사본이 아니라 영상, TensorBoard 이벤트, monitor,
  체크포인트, 평가 기록과 실행 설정을 모두 포함하는 완전한 학습 run이다.
  아래에 적힌 runs/... 경로는 이동 전 원래 위치를 나타내는 역사 기록이다.


1. 현재 권장 전진 정책
----------------------

디렉터리:
  05_forward_x_long

평가 성능이 가장 높은 배포용 조합:
  05_forward_x_long/evaluation/best_model.zip
  05_forward_x_long/evaluation/best_model_vecnormalize.pkl

최고 평가 리턴:
  208,913.447632 (누적 timestep 45,765,296)

마지막까지 학습된 조합:
  05_forward_x_long/final_model.zip
  05_forward_x_long/vecnormalize.pkl

마지막 평가 리턴:
  208,703.244596 (평가 timestep 47,565,296)

주의:
  모델 ZIP과 VecNormalize PKL은 반드시 같은 이름 계열의 파일끼리 사용한다.
  evaluation/best_model.zip에는 evaluation/best_model_vecnormalize.pkl을 사용한다.
  final_model.zip에는 같은 단계 루트의 vecnormalize.pkl을 사용한다.
  서로 다른 단계 또는 best/final 사이의 통계 파일을 섞지 않는다.


2. 정책 계보
------------

01_initial_sb3_baseline/best
  -> 02_lower_lr_epoch_finetune/final
  -> 03_lower_lr_epoch_long/final
  -> 04_target_kl_stabilization/final
  -> 05_forward_x_long/best 또는 final

각 화살표는 왼쪽 정책과 그에 대응하는 VecNormalize 통계를 불러와
오른쪽 단계에서 reset_num_timesteps=False로 추가 학습했음을 의미한다.
기본 Gymnasium 환경은 원시 observation과 물리 action 공간을 유지했다.
학습에서는 SB3 VecNormalize로 observation을 정규화하고, action wrapper로
정책의 [-1, 1] 출력을 물리 action [0, 2.7]로 변환했다.

4. 각 단계 디렉터리의 실제 run 구조
-----------------------------------

evaluation/best_model.zip:
  해당 run의 evaluation에서 가장 높은 평균 리턴을 기록한 정책.

evaluation/best_model_vecnormalize.pkl:
  evaluation/best_model.zip이 저장된 시점의 observation 정규화 통계.

evaluation/evaluations.npz:
  평가 timestep, episode return, episode length 원본 기록.

final_model.zip + vecnormalize.pkl:
  해당 run의 마지막 timestep 정책과 observation 정규화 통계.

checkpoints/:
  주기별 정책 ZIP과 각 시점의 VecNormalize PKL.

videos/:
  학습 도중 callback으로 녹화한 정책 실행 영상.

tensorboard/:
  PPO, rollout, 환경 지표를 포함한 TensorBoard 이벤트 로그.

monitor/:
  8개 병렬 환경의 episode monitor CSV.

resolved_config.yaml:
  실제 학습 실행 시 확정된 전체 설정. 내부 resume 경로는 이동 전 경로를 보존한다.

metadata.json:
  실행 시각, Git revision, Python 및 주요 패키지 버전.


5. 다른 방향 정책을 모을 때의 디렉터리 규칙
------------------------------------------------

권장 루트 구조:
  policies/path_tracking/forward/
  policies/path_tracking/backward/
  policies/path_tracking/left/
  policies/path_tracking/right/
  policies/path_tracking/diagonal_left/
  policies/path_tracking/diagonal_right/

각 방향 폴더 안에서는 이 폴더와 동일하게 01, 02, 03 순번으로 학습 단계를
저장한다. TRAINING_HISTORY.txt 첫 부분에 다음 정보를 반드시 기록한다.

  - joy_input 방향 벡터
  - 시작 모델과 VecNormalize 통계
  - 변경한 hyperparameter
  - 추가/누적 timestep
  - 최고 및 마지막 평가 리턴
  - KL 평균/최댓값과 clip fraction
  - 다음 단계가 best 또는 final 중 어느 정책에서 시작했는지

전진에서 다른 방향으로 전환할 때는 급격히 반대 방향으로 바꾸기보다
전진 -> 대각선 -> 측면 또는 후진과 같이 방향 벡터를 단계적으로 변경하는
커리큘럼을 권장한다.
